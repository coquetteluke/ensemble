## 2026-11-20 (font chooser and font sync, Luke's requests)

- Two font settings on the Mac (Settings, General, Fonts) and the iPhone (Settings, Fonts): the chat font, for what agents write, and the interface font, for everything else. Each row shows the font's name and a sample line set in that font, and a choice applies at once in every open window. `AppFont`, `FontRole`, `FontStore` and `CustomFontLibrary` in `Packages/EnsembleKit/Sources/EnsembleKit/UI/`; the chosen fonts travel in `Theme.chatFont` and `Theme.interfaceFont`, and the iPhone's `RemoteTheme.font` reads the interface font too.
- The default chat font stays Ensemble Serif (Roboto Serif). Source Serif 4 is a choice under its own name: Adobe's original files, unchanged, because "Source" is a reserved name that a modified copy may not carry (a test compares the files with the upstream ids). Also offered with no file added to the app: New York, Charter, Iowan Old Style, Georgia, Palatino, San Francisco, Avenir Next, plus Inter (the default interface font). Line spacing of agent text is worked out from each font's own line height so every choice sits about 1.6 lines apart.
- "Add Font" takes `.ttf` and `.otf` files (several at once): each is checked (must load as a font, 25 MB at most), copied to `Application Support/Ensemble/Fonts` on that device, registered for the running app and listed under its family name with Remove. Added fonts never enter the repository or a build, and the folder is left out of backups. A chosen font that is missing falls back to the default.
- Font sync between the paired Mac and iPhone (`FontSync` in `Remote/RemoteFonts.swift`): the newer choice wins on both devices, added font files are copied across in 192 KB pieces inside the encrypted connection (directly or through the relay), and a removed font is removed on the other device and does not come back. The iPhone starts every round (on connect, after a change on the iPhone, and when the Mac says its fonts changed). New messages `fontSync`, `fontFile`, `fontUpload`, `fontSettings` and `fontChunk` in `RemoteMessages.swift`; `RemoteProtocol.swift` and the protocol version are unchanged. An older Mac answers `unknownMessage` and the iPhone keeps its fonts; an older iPhone skips the frames it does not know. A received file is checked exactly like one added by hand, and the Mac only hands out files of its font library.
- The app grows by 2.07 MB (the two Source Serif 4 files and their licence). Notes and the list of fonts in `tools/fonts/README.md`.
- Interface font check: every Mac snapshot rendered with Georgia and with Avenir Next as the interface font (`--render-snapshots <dir> --interface-font <id>`, also `--chat-font <id>`), and 70 and 66 of those screens compared with the Inter versions. No broken layout. One fix came out of it: a button label that is too wide for a quarter-width pane now shortens with an ellipsis instead of wrapping inside the button (shared button styles in `Components.swift`). Native macOS controls (the Settings tabs, segmented pickers, plain buttons in forms) keep the system font.
- Known gaps: Inter has no italic in the app (its italic is a separate file), so italic text stays upright where Inter is the font. Georgia draws old-style figures, so numbers in tables look uneven with it.
- Verification: 1,332/1,332 `EnsembleKit` tests in 164 suites (32 for fonts and font sync: choosing, saving, falling back, adding and removing, refused files, two open windows following a choice, merge rules, files travelling both ways through the real message coding, refused uploads, an older Mac, and a loopback through the real `RemoteServer` and `RemoteClient`), Mac and iOS Simulator builds, Mac snapshots of the Settings section, the sample sheet and transcripts.
